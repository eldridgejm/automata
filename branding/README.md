# automata's logo

The mark is a cellular automaton: Rule 90, grown for eight steps from a single
cell (in the accent color). It draws a capital A, and, since every cell has
exactly one parent, a tree, like the hierarchy of materials automata manages.

| File | What |
|---|---|
| `automata-mark.svg` | The mark, for light backgrounds |
| `automata-mark-dark.svg` | The mark, for dark backgrounds |
| `automata-mark-ink.svg` | The mark in one color (ink) |
| `automata-lockup.svg` | The mark and the wordmark, for light backgrounds |
| `automata-lockup-dark.svg` | The mark and the wordmark, for dark backgrounds |
| `favicon.svg`, `favicon-*.png` | The first four steps, on ink, for small sizes (16, 32, 180, 512 px) |

The wordmark is "automata" in [Space Grotesk](https://fonts.google.com/specimen/Space+Grotesk)
600, tracked −0.03 em; in the SVGs its letters are outlines, so no font is
needed.
