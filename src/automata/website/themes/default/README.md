# Automata Default Theme

## Building

The default theme uses Tailwind CSS for styling. To build the CSS, you need to
have Node.js and npm installed. Then, run the following command in the theme
directory to install Tailwind CSS:

```bash
npm install tailwindcss tailwindcss/typography
```

To build, simply run `make`. This will generate the `styles.css` file in the
`static/static/` directory from `style.input.css`.
