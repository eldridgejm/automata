## Example Course

This is an example course website generated by Automata. Here is a
sample [link](https://example.com).

## Course Description

This example demonstrates how to use Automata to:

- Discover and build course materials (homeworks, lectures)
- Export artifacts to a website directory
- Generate a static course website

## Grading

- Homeworks: 50%
- Midterm: 20%
- Final: 30%
